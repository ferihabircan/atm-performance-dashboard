    KPI definitions

    Defined in the spirit of the EUROCONTROL Performance Review reports. All of them are ratios of additive sums, so any combination of airports and months is computed exactly from monthly aggregates (a unit test checks this against the raw flights).

    KPIDefinitionWhy it matters
    Arrival punctualityFlights with arrival delay ≤ 15 min ÷ all flightsWhat passengers and airlines feel
    ATFM delay per flightTotal ATFM delay minutes ÷ all flightsHeadline network capacity indicator
    Regulated flightsFlights with ATFM delay > 0 ÷ all flightsHow widespread flow measures are
    Additional taxi-outActual − unimpeded taxi-out time, per flightAirport congestion; fuel burned on the ground
    CO2 intensityCO2 (g) ÷ seat-kmComparable environmental efficiency

    CO2 method

    Formula

    fuel = LTO fuel(type)
     + cruise fuel per km(type) × distance
     + taxi fuel flow(type) × additional taxi min
CO2  = 3.16 × fuel        (ICAO factor)

    Caveats

    • Indicative coefficients. Per-type fuel values are for illustration, not certified factors.
    • Better sources: the ICAO Carbon Emissions Calculator methodology or EUROCONTROL emission models.
    • Synthetic demo data. 62,080 flights at ten airports in 2025, built to reproduce typical seasonal patterns.

    Run it yourself

    The full Streamlit app adds CSV upload of your own flight data and a feedback form used in user-testing sessions.

    git clone https://github.com/ferihabircan/atm-performance-dashboard
cd atm-performance-dashboard
pip install -r requirements.txt
streamlit run app.py                                  # full app
PYTHONPATH=src python scripts/export_site_data.py     # refresh this website
PYTHONPATH=src pytest -q
